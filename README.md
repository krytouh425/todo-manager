# Todo Manager

Внутренний CLI-инструмент для управления задачами команды.

## Установка
python todo.py

## Команды
- add "название" [приоритет] — добавить задачу
- list — показать активные задачи
- list --all — показать все задачи
- done [id] — отметить задачу выполненной

## Приоритеты
low / normal / high
